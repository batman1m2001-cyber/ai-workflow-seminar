The shape

RAG, a router, parallel checks, an agent loop, a harness: all workflows. They differ in one thing only, and it's the next tab.

Who decides the next step?

Anthropic's Building effective agents draws the line with one question:

Workflows are systems where LLMs and tools are orchestrated through predefined code paths. Agents are systems where LLMs dynamically direct their own processes and tool usage.

Run Linh's email both ways and count.

The real distinction

Both are workflows: steps and edges. The difference is who picks each edge, code or the model. That's a property of each edge, not of a whole system, and most real systems mix both.

Not a takedown: the brief's own tool, eval and security harnesses are exactly what a workflow gives you, and the one open-ended part is where multi-agent pays: an orchestrator splits the research, workers run in parallel, a step merges them. Draw it and it's a workflow whose nodes are agents. A handoff is an edge the model picks; A2A is an edge between processes.

X-ray: orchestrator and workers

So

Multi-agent is a workflow whose nodes are agents. The hard part isn't the agents: it's the wiring, the parallelism, and the context between them. That's an engine's job.

The map

Two questions place any system: how fixed is the structure? (left to right) and how much of the work is LLM calls? (bottom to top). Plain code sits bottom-left and a coding agent top-right. Most of what ships lives in between, as hybrids:

workflow with an agent nodea fixed pipeline where one step is a small agent
agent with workflow toolsthe model picks among tools that are fixed pipelines
orchestrator–workersa model splits the task; workers run in parallel; results merge
evaluator–optimizergenerate, check, retry: a loop with a model as the judge

Room exercise: click the products under the map one by one. Before each click, ask where it lands.

Others reached the same view

HumanLayer's 12-factor agents: production agents are mostly deterministic code with LLM steps sprinkled in, so own your control flow. LangChain's own framing: production systems combine workflows and agents.

So

Every point on the map is a workflow. The only question left is: when do you want the model to pick the edges? That's Act 3.
