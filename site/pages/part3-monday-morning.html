Chapter 11 · Monday morning

Friday's demo worked. On Monday at 8 am, 50 emails arrive at once. Run the Part I agent over them with its harness taken off, card by card, against the real inbox, web and model.

Each failure is an engine feature

Every failure has a known fix, and none of them is about the model. Write them by hand and the 15-line agent becomes 150 lines, the same 135 lines every team writes. Or notice that each fix is a part of the engine from Part II: a gate is a node, a cap is the scheduler, a trace is the engine watching itself.

The truth

A production agent is a workflow engine with a model inside some nodes.

Chapter 12 · The real system on OperonX

Here is the whole meeting-prep assistant as one OperonX graph. The zones carry the course brief's own box names, so the brief's diagram and Studio's drawing match. The wiring is two lines at the end.

@graph
def prepare(mail, deliver):
    email = email_agent(email=mail)
    extract_company = extract_company_name(email=mail)
    web_research = web_research_agent(company=extract_company["company"])
    calendar = calendar_agent(company_id=extract_company["company_id"])
    company_info = company_info_agent(company=extract_company["company"], company_id=extract_company["company_id"])
    memory = memory_agent(
        email=mail, company=extract_company["company"], contacts=company_info["contacts"],
        history=company_info["history"], meetings=calendar["meetings"], notes=company_info["memory"],
        website=web_research["website"], news=web_research["news"], people=web_research["people"],
    )
    report = report_agent(company=extract_company["company"], company_name=extract_company["name"],
                          evidence=memory["text"])
    human_approval = human_approval_gate(email=mail, deliver=deliver, company=extract_company["company"],
                                         brief=report["brief"], ok=report["ok"], problems=report["problems"])
    done = ops.settle(a=email["outcome"], b=human_approval["outcome"])

    START >> email >> if_(email["lead"] == True, extract_company).else_(done)  # noqa: E712
    extract_company >> [web_research, calendar, company_info] >> memory >> report >> human_approval >> done >> END

Open it in Studio: it draws this graph from the code, and every run is a trace you can click through.

The whole system, live

  1. Pick Linh's email above and press Send as customer. It goes over SMTP to the inbox.
  2. The inbox starts a run, and Studio lights up the graph zone by zone.
  3. “[Approve?] Brief: …” lands in the inbox. Click Approve: the brief goes to sales and into memory.
  4. Now send an attack. It's held at the gate in milliseconds, and nothing is sent.
The truth

Part I's agent is one node in this graph. Everything around it is the workflow, and the engine runs it.
