Workflow Is All You Need

Agents, RAG, tool calling, context engineering: the same primitives, one engine. Every page has runnable code: read it, change it, press Run.

Every six months, a new “engineering”

Prompt Engineering→ RAG→ Function Calling→ Agents→ Context Engineering→ Harness Engineering→ Loop Engineering→ Graph Engineering→ …

At 8 am an email arrives from a lead. By the meeting, sales wants a brief. How many agents does that take?

This seminar takes the agent world seriously. We build an agent part by part, look at its shape, measure when agents pay, break it on Monday morning, and run the whole system on a workflow engine — live, end to end.

The thesis

Every GenAI system is a workflow. The real question for each step is who decides the next one: your code, or the model.
